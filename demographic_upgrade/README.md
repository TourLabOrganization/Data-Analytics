# Tour Navigator 성별 연령별 지역지표 확장 v4

업로드한 20260927163120 ZIP을 분석한 로컬 구현입니다. 원본 data/source.zip은 업로드와 같은 바이트입니다. 전국 히트맵242행·230지역, 순위100행·94지역, 연령 상세880행, 성별 상세220행입니다. 성별×연령 교차표는 없습니다.

## 재현

Python3.12 및 requirements.txt의 패키지를 사용합니다. `python prepare_demographics.py` → `python analyze_demographics.py`로 원자료부터 대응표·군집·CSV·PNG를 재생성합니다. 장소 원장은 `../age_upgrade/results/nationwide_places_age_clustered.csv`, 코스 목록은 `../tour_scoring/data/citytour_app_zip.json`을 읽고, 앱 설정 `region-demographics.json`은 `../tour_scoring/data/`에 씁니다. 한글 그래프에는 Noto Sans CJK KR 또는 Windows 맑은 고딕을 설치하세요. Linux에서는 분석 스크립트의 font 경로를 설치 위치로 조정할 수 있습니다. 점수표는 함께 제공되는 형제 폴더 tour_scoring이 있는 상태에서 `node export_score_examples.cjs`로 재생성합니다.

## 검사와 적용

- 순위 칼럼을 제외한 동일키·동일값 중복 age96행/sex24행 제거.
- 인천 제물포·서해·검단·영종4지역은 동일키 다른값과 범위 이상값으로 보류. 작은값과 큰값을 임의 합산하지 않음.
- 연령8구간·성별2구간의 완전성, 범위0~100, 합100±0.1, 히트맵 남성값 대조를 통과한90지역 사용.
- 상세표 없는136지역 제외. 상세표는 남성 구성비 상위 목록에서 선택되었으므로 전국 대표 표본이 아님.
- 54개 앱 지역을 잠정 연결하여 장소951행·코스127개에 지역 보정의 입력을 제공. 서울·부산 등 광역 지역이나 고성 같은 중복 지명은 임의 집계하지 않음.
- 결과 CSV는 입력 3,109행(2026-09-29 맥도날드 9곳 제외)·v3 연령 칼럼을 보존하고 지역 주변비율·연결상태·R군집을 추가.

## 산식

p=지역별 해당 범주의 원비율 / 같은 분류의 합계. b=90개 정상 지역의 p 중앙값. z=max(0,min(1,log2(p/b))), p=0이면 z=0.
D=0.02×q×(0.75z_age+0.25z_sex), q=0.5 잠정 지역 연결. 계수는 추정값이 아닌 시범 정책. 최대0.01. 미입력 성별항은0, 가중치 재분배 없음. 70대 원자료의 상한이 확인되지 않아 Q1=70대 이상은 새 지역 연령항을 보류하되 성별항과 기존60대 이상 Top30 보정은 가능.

장소: 기존 점수+clip(v3 장소연령 A+D,0,0.02). 테마: v3 지역항+D평균을 ±0.05에 제한. 시티투어: v2 점수+clip(v3 경유지연령 평균+코스 대표지역 D,0,0.02), 그 뒤 전체 정렬·지역대표 최대5개.

본 자료만으로 개인 관광취향, 관광지 성별 방문률, 방문확률, 성별×연령 교차비율, 체류시간을 추정하지 않습니다. 원자료의 지역명을 공식 행정경계 코드로 검증한 것은 아닙니다.

## 군집

90개 지역×10변수(8연령+2성별), X=[sqrt(.75)sqrt(p_age),sqrt(.25)sqrt(p_sex)]. raw/PCA95와 k2~6 비교. 대표raw k2, 실루엣0.3165, 시드ARI1, PCA2축83.21%. 연령만 사용한 민감도ARI0.9556. R01 40지역/R02 50지역은 탐색적 지역분포 유형이며 점수에 군집번호를 더하지 않습니다. 기존 C사용자/G장소/A연령목록 군집과 구별합니다.
