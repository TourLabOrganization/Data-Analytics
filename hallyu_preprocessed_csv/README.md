# 2026 해외한류실태조사 사용 지표 CSV

원문은 사용자가 첨부한 20260330185020707.pdf, 정식 표제는 「2026 해외한류실태조사」, 기준연도는2025년입니다. CSV는 개인 응답 원자료가 아니라 원문 발표 집계치와 현재 코드에서 사용한 변환값입니다. 엑셀 한글 호환을 위해 UTF-8 BOM으로 저장했습니다.

## 파일

1. hallyu_2026_source_indicators.csv: 그림2-1-12의2025 추천의향12개 분야. 활성4종과 보관용 비활성8종 표시.
2. hallyu_2026_scoring_inputs.csv: 드라마·영화·예능·음악4개 활성 분야의 r·z·H 변환값. 실제 Node 함수 결과와 대조.
3. hallyu_2026_country_scope.csv:30개 조사 대상 국가·지역 및 ISO 코드. 국가별 점수표가 아니라 적용대상 확인 목록.
4. hallyu_2026_eligibility_rules.csv: Q6·H1·Q1/H2·H3·H4 적용 조건과 미디어 태그 조건.
5. hallyu_2026_design_parameters.csv: .5/.2/.1 등 설계 계수. 통계 연보 측정값과 분리.
6. hallyu_2026_reference_only.csv: 명세서에서 참고한 서비스 구매의향·콘텐츠 소비량. 점수 및 체류분 직접 환산에는 미사용.
7. hallyu_2026_source_metadata.csv:조사기간·전체 표본·모집단·원자료 범위와 PCA 미사용 표시.
8. hallyu_2026_data_dictionary.csv:각 파일의 칼럼과 예시.

## 현재 적용식

r=추천의향%/100. H4 직접 응답이 있으면 z=e. 미응답이고 모든 통계 적용 조건을 충족하면 z=.5+.2*(r-.5), 적용 대상 밖이면 z=.5. H=.1*sum(M_k*(z_k-.5)). CSV의 H는검증된 단일태그 M=1이라는 가정의 계산 예시입니다. 실제280코스는 기본 미디어 태그가 미구축되어 기본 H=0입니다.

전체27,400표본을 각 콘텐츠 지표의 분모로 대입하지 않았습니다. 개인 응답·분야별 표본수·국가×성별×연령 추천의향을 생성하지 않았습니다. 국가 코드와 추천율을 교차결합하여30개 독립 관측값으로 늘리지 않았습니다.

이번 PCA 그래프는 별도 관광데이터랩 자료로 계산했습니다. 이 한류 추천의향4개를 PCA에 투입하거나 국내 지역별 성연령 통계로 사용하지 않았습니다. 서비스 구매의향과 월간 콘텐츠 소비시간도 현장 체류시간의 실측값이 아닙니다.
