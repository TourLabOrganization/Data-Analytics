# Tour Navigator 연령 인기도 확장 v3.0.0

업로드한 관광데이터랩 CSV 6개를 기존 설문·한류·체류 엔진 v2 위에 연결한 **로컬 실행용 구현**입니다. 운영 GitHub 앱에 배포하지 않았습니다. 기존 상세 설명은 README_V2.md에 보존했습니다.

## 실행

```bash
npm start
# http://127.0.0.1:8787
npm run demo:v3
npm test
```

Node.js 18 이상, 별도 npm 의존성 설치 없음. `const v3=require('./src/scoring-v3.cjs'); v3.recommendV3(input)` 또는 `node src/cli-v3.cjs examples/v3_domestic20.json`으로 실행합니다. v2의 설문 입력·H1~H4·체류·일정 API 계약은 그대로 유지합니다.

## 질문 → 점수 연결

- Q1 연령(0부터 세는 보기): 1/2/3/4 → 20/30/40/50대, 5/6 → 60대 이상. 10대·미응답은 신규 연령 가산 없음.
- Q6 국내 모드(`answers[5]===0`)에서만 사용합니다. 이는 시범 적용 범위이며 CSV의 국적 모집단을 검증했다는 뜻이 아닙니다.
- 장소 가산 `A=0.03 × q × (해당 연령 비율/그 연령 Top30 최대 비율)`.
- 명칭으로 유일하게 연결된 44곳은 잠정값 q=0.5입니다. q는 정확도 50%라는 통계값이 아니라 보수적 감쇠계수입니다. 최대 +0.015점입니다.
- `ageOptions:{strictVerified:true}`면 검증 완료된 연결만 허용합니다. 현재 검증 완료 0곳이므로 연령 가산은 전부 0입니다. UI의 검증 모드 체크박스와 연결되어 있습니다.
- `beta`는 기본 0.03(설계값), 선택 변경 허용 범위 0~0.05. 아래 최대값은 기본 beta 기준입니다.
- 해당 연령 Top30 미등장·앱 미연결·동명이소 보류는 가산 0. 방문량 0이나 낮은 선호로 해석하지 않습니다.

## 장소 → 테마 → 시티투어

`applyAgeToPlace({placeId,score},answers)`는 기존 장소 점수에 A를 더합니다. 기존 점수를 호출자가 제공해야 하며, `agePlaceRanking`은 연령 가산만 정렬한 진단 목록입니다.

테마는 페이지의 비숙박 장소 전체(주요 장소와 주변 관광지 포함)를 분모로 평균합니다. 기존 국내 지역 보정 `reg`와 새 가산을 합쳐 [-0.05,+0.05]로 제한하므로 테마별 `age.effectiveBonus`가 원래 가산보다 작을 수 있습니다. C1~C10 유형 점수를 변경하거나 A군집을 C유형으로 바꾸지 않습니다.

시티투어는 화살표로 분리된 경유지 중 명칭·지역이 유일한 후보만 linkWeight=0.5로 연결합니다. 이것도 실제 승하차 방문지 확인은 아닙니다. 같은 장소 후보는 중복 제거하고 미연결 조각도 분모에 남깁니다. 구분이 불명확한 31개 코스는 가산하지 않습니다. `A_course=Σ(A_place × linkWeight)/전체 고유 슬롯 수`. 최종 점수에 더한 뒤 전체 280개 코스를 정렬하고 지역별 1개, 최대 5개를 선택합니다. 기본 코스 최대 가산 상한은 +0.0075, 실제값은 평균으로 더 작습니다.

`data/age-candidate-profiles.json`의 themes는 페이지 장소 ID, tours는 코스 원문 행을 고정한 스냅샷입니다. 테마·코스를 바꾸면 프로필을 함께 갱신해야 합니다. tours의 원문 행이 달라지면 기본 프로필은 자동 비활성화됩니다. 임의의 프로필 override는 공급자 책임입니다.

## 데이터 한계와 군집

CSV는 각 연령 및 전체 각각 Top30, 총180행·고유70관심지점입니다. 전체 비율을 연령별 비율의 분모로 사용하지 않습니다. 주소·좌표·방문 건수·분모·표본 수·체류시간은 제공되지 않았습니다. 앱3,118곳 중44곳(1.41%)만 잠정 연결되며 보문사·송정해수욕장은 동명이소 위험으로 보류했습니다.

연령 A군집은 70곳의 5차원 Top30 등장 순위 패턴에 대한 탐색 분석입니다. raw와 PCA95, k=2~6 비교 결과 raw k=3, 실루엣 0.3949, seed ARI 1.0000. 비율 기반으로 바꾸면 ARI 0.1732로 민감하므로 **군집 번호로 점수를 가산하거나 미관측 장소에 점수를 전파하지 않습니다.** 체류 산식과 한류 선호 산식도 그대로입니다.
