# Tour Navigator 분기형 유형 설문 구현

Python 3.10 이상, 외부 패키지 불필요. 이 폴더에서 실행합니다.

```bash
python score_survey.py example_answers.json
python score_survey.py example_close_answers.json
python verify_survey.py
```

`survey_config.json`의 고정 문항과 배점을 사용합니다. 미완료 입력은 다음 문항을 반환하며, 모든 활성 문항에 답하면 C1~C10 점수와 가산 내역, 최종 성향을 반환합니다. `F1`은 접전 후보에 따라 동적으로 생성됩니다.

앱에서 응답을 수정하면 공통 또는 B 수정 시 기존 F1을 삭제하세요. S4를 수정하면 B 응답도 삭제하세요. 서버에서는 비활성 분기 응답을 오류로 처리합니다.

신규 문항 설계안이며 기존 v4 추천 함수에 바로 연결하지 않습니다. 유형 명칭·후보군·판정 기준이 바뀌어 버전을 구분해야 합니다. 점수는 확률이나 코사인 유사도가 아닙니다.

## 6.1 변경

B1~B7에 D 없음 선택지를 추가했습니다. 응답은 기록하고 모든 C 기여는 0입니다. 기존 점수를 삭제하거나 재배분하지 않습니다. 공통 문항과 A~C 선택지 및 유형명은 6.0과 같습니다. F1 조건은 유지합니다.

응답자용 PNG는 공통 2장, 분기 3장, 추가 확인 1장입니다. 인쇄용 F1은 진행자가 계산된 후보 번호를 기입한 뒤 제공합니다. 01~10은 각각 C1~C10에 대응하며, 안내된 번호 중 선택한 C 또는 BALANCED만 서버로 전송합니다. 전체 열 가지를 일괄 후보로 간주하지 않습니다.
