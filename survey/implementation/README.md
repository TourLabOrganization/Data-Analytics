# Tour Navigator 분기형 유형 설문 구현

Python 3.10 이상, 외부 패키지 불필요. 이 폴더에서 실행합니다.

```bash
python score_survey.py example_answers.json
python score_survey.py example_close_answers.json
python verify_survey.py
```

`survey_config.json`의 고정 문항과 배점을 사용합니다. 선택지 배점은 원점수이고, 결과 점수는 유형별 100점 만점으로 환산한 값입니다. 미완료 입력은 다음 문항을 반환하며, 모든 활성 문항에 답하면 C1~C10 점수와 가산 내역, 최종 성향을 반환합니다. `F1`은 접전 후보에 따라 동적으로 생성됩니다.

S4는 서로 다른 선택지 두 개의 목록입니다(예: `"S4": ["A", "H"]`). 두 관심사에 연결된 B 문항(1~2개)이 모두 활성화됩니다. 앱에서 응답을 수정하면 공통 또는 B 수정 시 기존 F1을 삭제하세요. S4를 수정하면 더 이상 활성이 아닌 B 응답도 삭제하세요. 서버에서는 비활성 분기 응답을 오류로 처리합니다.

신규 문항 설계안이며 기존 v4 추천 함수에 바로 연결하지 않습니다. 유형 명칭·후보군·판정 기준이 바뀌어 버전을 구분해야 합니다. 점수는 확률이나 코사인 유사도가 아닙니다.

## 6.1 변경

B1~B7에 D 없음 선택지를 추가했습니다. 응답은 기록하고 모든 C 기여는 0입니다. 기존 점수를 삭제하거나 재배분하지 않습니다. 공통 문항과 A~C 선택지 및 유형명은 6.0과 같습니다. F1 조건은 유지합니다.

응답자용 PNG는 공통 2장, 분기 3장, 추가 확인 1장입니다. 인쇄용 F1은 진행자가 계산된 후보 번호를 기입한 뒤 제공합니다. 01~10은 각각 C1~C10에 대응하며, 안내된 번호 중 선택한 C 또는 BALANCED만 서버로 전송합니다. 전체 열 가지를 일괄 후보로 간주하지 않습니다.

## 6.2 변경

S4 바다(E)의 점수를 C2 +2 · C3 +2 · C9 +2에서 C2 +1 · C3 +1 · C9 +4로 바꿨습니다. 선택지 총점 6점은 같습니다. 바다를 골라도 자연 해양형(C9)이 결과에 거의 나오지 않던 문제를 줄이기 위한 조정입니다. 전수 경로 중 바다를 고른 경로에서 C9가 결과에 포함되는 비율이 18.8%에서 40.1%가 됐습니다.

F1이 나오는 조합이 바뀌어 완료 경로는 141,833개에서 141,897개가 됐습니다. 기본 경로 47,628개, 7~8문항 종료, 모든 유형 단일 결과 가능, D 무변경 조건은 그대로 통과합니다. 응답자용 설문지와 PNG에는 점수가 표시되지 않아 바뀌지 않았습니다.

## 6.3 변경

문항과 선택지별 원점수는 6.2와 같습니다. 판정 방식만 바꿨습니다. 유형마다 한 경로(S1~S6과 B 한 개)에서 받을 수 있는 최대 원점수가 C1 18, C2 15, C3 16, C4 17, C5 18, C6 10, C7 14, C8 11, C9 9, C10 9점으로 두 배까지 차이 나서, 원점수를 그대로 더하면 선택지에 자주 나오는 유형이 결과를 차지했습니다. 이제 원점수 1점을 `100 / 최대 원점수`점으로 환산해 모든 유형의 만점을 100점으로 맞춥니다. 최대 원점수는 코드가 설정에서 직접 계산하고 `scoring.type_max_raw`와 다르면 실행을 멈춥니다.

경계값도 100점 척도로 바꿨습니다. F1은 1·2위 차이가 12점 이하일 때 나오고, F1 선택은 +20점(균형은 20점을 후보 수로 나눔), 최종 복합 판정은 최고점과 12점 이내, 상대 가중치는 12점 차이마다 2배입니다. 결과 원장의 `raw_points`는 원점수, `contribution`은 환산 점수입니다.

모든 선택지가 같은 빈도라고 가정한 전수 경로에서 결과 비중은 문화 산책형(C4) 21.2%→14.9%, 트렌드 탐색형(C1) 19.9%→14.3%, 자연 해양형(C9) 4.0%→8.6%, 역사 전통체험형(C10) 3.3%→9.1%가 됐고 가장 많은 유형과 가장 적은 유형의 비는 6.4배에서 2.5배로 줄었습니다. 바다를 고른 경로에서 C9가 결과에 포함되는 비율은 40.1%에서 80.0%입니다. F1이 나오는 기본 경로는 66.7%에서 49.1%로 줄어 완료 경로는 141,897개에서 109,552개가 됐습니다. 실제 응답자 분포에 맞춘 조정은 파일럿 응답으로 다시 해야 합니다.

`example_close_answers.json`은 F1에서 균형 선택지를 고르도록 바꿔 8문항 복합 성향 예제를 유지했습니다. 환산 뒤에는 C7 경험을 고르면 C7 단일 성향이 됩니다. 응답자용 설문지와 PNG에는 점수가 표시되지 않아 바뀌지 않았습니다.

## 6.4 변경

S4를 관심사 두 가지 선택으로 바꿨습니다. 서로 다른 선택지를 정확히 두 개 받아 선택지 순서대로 저장하고, 두 선택지의 원점수를 모두 더합니다. 두 관심사는 같은 비중입니다. 두 관심사에 연결된 B 문항에 B 번호 순서로 모두 답하며, 같은 B 문항에 연결되면(A·B, D·E) 한 번만 묻습니다. 한 개만 고르거나 같은 값을 두 번, 세 개 이상을 보내면 오류입니다. 결과에는 `interests`(S4 두 값)와 `active_branches`가 들어갑니다.

선택지별 원점수, 100점 환산, 경계 12점, F1 +20점, 상대 가중치 규칙은 6.3과 같습니다. 최대 원점수만 S4 두 선택과 그 B 문항 기준으로 다시 계산해 C1 23, C2 19, C3 20, C4 19, C5 22, C6 10, C7 17, C8 11, C9 11, C10 15점이 됐습니다.

S4 조합 36개에서 기본 경로 730,296개, 완료 경로 1,756,396개를 모두 검증했습니다. 7문항 0.4%, 8문항 20.1%, 9문항 79.5%로 대부분의 응답자가 한 문항을 더 답합니다. F1이 나오는 기본 경로는 52.0%, 결과가 복합 성향인 완료 경로는 35.5%입니다. 결과 비중은 문화 산책형(C4) 13.8%가 가장 많고 가족 체험형(C3) 6.1%가 가장 적어, 두 유형의 비가 2.5배에서 2.26배로 줄었습니다. 바다를 고른 경로에서 C9가 결과에 포함되는 비율은 56.7%로, 바다와 함께 고른 다른 관심사가 점수를 나눠 가져 6.3의 80.0%보다 낮습니다.

`example_answers.json`은 S4 드라마·K팝 촬영지와 공연·콘서트(둘 다 B1)로 7문항 K컬처 탐방형 단일 성향, `example_close_answers.json`은 드라마·K팝 촬영지와 야경(B1, B6)에 F1 균형 선택으로 9문항 복합 성향 예제입니다. 응답자용 설문지와 PNG는 S4를 체크박스 두 개 선택으로 바꾸고 안내 문구를 고쳐 다시 만들었습니다.
