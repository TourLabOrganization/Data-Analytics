- Tour_Navigator_Scoring_Specification.docx: 기존 질문별 상세명세에 연령자료·군집·점수·시티투어 배정을 추가한33쪽 통합본. 25~32장 참조.
- tour_scoring/: v3 Node.js 실행 엔진과 설문 UI. npm start / npm test / npm run demo:v3.
- pca_notebook/: 실행된 ipynb, 원장·PCA 입력, 결과표, PNG15개. 그중10~15번은 이번 연령분석 그림.
- age_upgrade/: 원본 ZIP 사본, 정제자료, 명칭 대응표, 전국3,118행 연령 결합CSV, 재현 Python 코드, 전후 점수표.

원자료는 고유70관심지점의 연령별 Top30 표입니다. 44곳의 명칭 연결은 잠정 상태이고 군집3개는 탐색 결과입니다. 연령별 전국 방문량이나 체류 실측을 추정한 결과가 아닙니다. 운영 앱에 배포하지 않았습니다. 각 폴더 README의 적용 범위와 실행법을 확인하세요.
